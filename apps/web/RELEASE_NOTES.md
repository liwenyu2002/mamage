# MaMage Web 更新说明

## 2026-07-26 生产整合版（待发布）

本版本在现有图库和全媒体编辑台基础上新增视频剪辑工作台，并将视频能力统一接入生产后端 `/api`。页面继续使用当前登录用户的 JWT，不再依赖独立的本地视频后端。

### 全媒体编辑台

- 将推文、小红书、新闻稿、通讯稿和微博归入“文本内容”二级菜单。
- 在全媒体编辑台中增加“视频剪辑”入口。
- 统一文本内容与视频剪辑入口的样式、悬停反馈和选中状态。
- 顶部导航使用黑色表示当前栏目、灰色表示未选栏目，并为文本类型切换增加平滑过渡。

### 视频素材

- 支持搜索并多选生产项目，一次载入一个或多个项目中的视频。
- 支持将多个生产项目的名称、时间、标签和视频元数据交给 AI 进行跨项目编排。
- 保留 MP4、MOV、WebM 本地文件上传；上传完成后素材可随工程保存并参与服务端导出。
- 素材区可直接拖拽到 V1 主视频轨道。
- 云端工程重新打开时会通过素材 ID 刷新媒体访问地址，避免旧签名失效。

### 人工剪辑

- 支持片段添加、拖拽排序、删除、分割以及撤销和重做。
- 支持点击时间尺定位播放头，并修正播放头、预览画面和轨道片段之间的时间换算。
- 支持在同一素材片段内部跳转，不再自动回到素材起点。
- 支持拖拽片段左右边缘调整入点和出点；视频片段不超过源素材时长。
- 新增“留白”片段，播放和导出时输出黑场与静音；留白时长不受源素材限制。
- 支持调整片段速度、音量和转场等属性。
- 修改后自动保存云端工程，并在浏览器 `localStorage` 中保留恢复备份。

### AI 编排和导出

- 支持根据提示词、目标时长、风格和素材元数据生成粗剪方案。
- AI 粗剪结果会直接写入时间线，并显示所用模型、摘要和片段选用理由。
- 支持提交 FFmpeg 导出任务、查看进度、取消任务以及下载完成的 MP4。
- 支持导出剪辑单，便于人工复核和后续加工。

### 兼容性与已知限制

- 生产项目选择为只读操作，不会修改原项目数据。
- 从生产项目直接读取、但尚未上传为视频编辑资产的素材可以预览和参与 AI 编排；开始 FFmpeg 导出前，需要从本地补充上传对应源文件。
- 正式工程以服务端 MySQL 数据为准，`localStorage` 仅作为浏览器侧备份。
- 前端生产部署必须将同源 `/api/*` 转发到配套的 MaMage Server 生产整合版。

### 发布前检查

```bash
npm ci
npm run build
```

构建完成后，还需使用真实测试账号检查登录、项目多选、素材上传、自动保存、AI 粗剪和 FFmpeg 导出流程。

# 全媒体编辑台样式原型

本地静态原型，用于确定样式方向；**未接入 React 代码**，未部署。用浏览器直接打开 HTML 即可
（无外链、无 CDN、断网可用）。

## 文件

| 文件 | 说明 |
| --- | --- |

| `media-studio-style-v2.html` | 第二版：按交互频率分层，默认只有纸面（自绘视觉） |

| `media-studio-style-v5.html` | 第五版（当前推荐）：操作全部收进**右侧边栏**，左右等宽使画布居中 |

## v5：双侧栏 + 画布居中

在 v4 基础上的最后一处调整：

- **撤销 / 重做 / 更多 / 预览 / 复制到公众号 / 页面样式 / 发布检查** 收成**贴着画布的一列裸图标按钮**：
  34×34、无外层容器/无底板（`background: transparent`）、距纸面 8px，悬停才出浅底与文字提示；复制按钮为实心深色。
  不做面板、不做分组标题、不加角标。
- 布局改成 **左 264 / 画布 / 右 264** 三栏等宽，实测纸面中心 = 720px，与 1440 视口中心完全一致（`paperCenter === viewportCenter`）。
- 顶栏只保留生产结构：品牌 + 导航 + 中间的标题/已保存 + 显示设置/账户；这条"第二层 bar"的内容一分为二（标题进顶栏中间，动作进右栏）。
- 顶栏里的稿件标题**沿用导航项样式**（13px / 550 / 胶囊内边距 / `--glass-hover`），不再是加粗大标题；
  标题与「已保存」一起放进**和左侧导航分组完全相同的玻璃胶囊底纹**（`--glass-material` + `--glass-edge` + `--glass-backdrop`，圆角 28px），
  实测材质与左侧分组逐项一致（背景渐变/底色/描边阴影/backdrop 均相同）。
- 左右侧栏贴近画布（grid 用 `1fr | 侧栏 | 画布 | 侧栏 | 1fr`），画布中心仍等于视口中心（实测 720 = 720）。
- 窄屏（≤1080）左右栏都收起，dock 承担插入/页面样式/检查/复制。

## v4：单层顶栏 + 常驻左栏

根据评审反馈做的两处结构调整（仍复用 v3 的生产样式表与顶栏结构）：

1. **左边栏改回常驻完整面板**：`样式与插入` 一栏固定显示（分类 tab、样式卡、更多插入方式），
   不再"图标栏点开再出右侧抽屉"。窄屏（≤1080）才收起为 dock + 底部抽屉。
2. **第二层文档条并入全局导航**：标题输入与「已保存」放进顶栏品牌组与右侧动作之间的空白处；
   撤销 / 重做 / 更多 / 预览 / 复制到公众号 全部收到顶栏右侧，删掉原来那条独立 bar。
   桌面顶栏保持一行 48px；≤900 时右侧动作收起、只留标题，动作进底部 dock。

顶栏仍然是生产 `mamage-header` 结构与样式，这里只覆盖了 `nav-actions` 的换行与拉伸，
让"文档槽"能插进中间空白处。

## v3：复用生产样式

v3 不再自绘一套视觉，而是直接引用仓库里的生产样式表与顶栏结构：

```html
<link rel="stylesheet" href="../../apps/web/src/global.css" />
<link rel="stylesheet" href="../../apps/web/src/liquidGlass.css" />
<link rel="stylesheet" href="../../apps/web/src/ui/glass.css" />
<link rel="stylesheet" href="../../apps/web/src/ui/navigation.css" />
<link rel="stylesheet" href="../../apps/web/src/ui/ui.css" />
<link rel="stylesheet" href="../../apps/web/src/ui/darkTheme.css" />
```

- **顶栏**：完全按 `App.jsx` 的结构复刻（`mamage-header / mamage-topbar / mamage-nav-brand-group /
  mamage-nav-links / mamage-nav-search-group / mamage-nav-actions / mamage-account-group /
  mamage-user-chip`），玻璃材质由 `data-glass` 属性驱动，未改任何顶栏样式。
- **编辑台**：按钮统一用 `mamage-button`（primary / small / borderless），面板沿用
  `--liquid-glass-*`、`--lg-radius*`、`--lg-text` 等生产令牌，与顶栏同一套材质。
- 唯一需要的补偿：生产样式只重置了点击高亮、没有重置 `button` 默认外观，所以自定义控件显式去掉了浏览器默认的浅灰底与边框。
- 顶栏在生产里是 `z-index: 1000` 的 sticky 层，抽屉/遮罩层级相应提到 1100/1200。

注意：v3 是静态原型，需要与仓库同级目录一起打开（`docs/prototypes/` 与 `apps/web/src/` 必须保持相对位置）。

## v2 的频率分层依据

| 层级 | 频率 | 包含 | 位置上怎么处理 |
| --- | --- | --- | --- |
| T1 | 每几秒 | 正文写作、看图、改标题 | 纸面独占中央，无侧栏挤压；状态条极轻 |
| T2 | 每分钟 | 插入内容、撤销/重做、预览、复制到公众号 | 左侧图标栏（点开才出内容清单）+ 文档条；复制固定在文档条 |
| T3 | 每篇 1–2 次 | 页面样式（字号/行距/主题色）、组图样式、发布检查 | 右下两个入口，打开右侧抽屉；不占版面 |
| T4 | 偶尔/跨稿 | 切换平台与内容类型、稿件备份、导出、搜索/通知/中转站 | 顶栏「更多」菜单 + 顶栏图标；不再常驻 |

实测（1440×940，Playwright 统计当前视口内可见的可点元素）：

| 版本 | 可见可点元素 | 其中常驻 | 按需出现 |
| --- | --- | --- | --- |
| v1 | 52 | 49 | 3 |
| v2 | 33 | 26 | 7 |

v1 把 T3/T4 的内容（样式库整列、页面样式整列、平台 + 内容类型两排）一直摆在屏幕上；
v2 让纸面占满宽度，其余按层级收进「点一下才出现」的抽屉、菜单和选中块浮条。

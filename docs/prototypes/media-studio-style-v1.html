样式优化说明

全媒体编辑台 · 本地样式预览 v1

1层级与结构

  • 顶部保留产品导航，但把「编辑台身份 + 当前稿件 + 自动保存状态」收进工作室标题区，打开就知道自己在哪。
  • 平台（文本内容 / 视频剪辑）做成带副标题的大切换卡；内容类型（推文 / 小红书 / 新闻稿…）变成独立胶囊行，不再和平台挤在一张窄条里。
  • 工作区三栏：样式库 / 画布 / 页面样式，边界用发丝线和浅底区分，画布保持纸面质感。

2视觉语言

  • 统一为「墨色 + 米白 + 一点墨绿」：主操作实心墨黑，状态/选中用墨绿，减少蓝灰玻璃与重阴影叠加。
  • 面板统一 10–16px 圆角、1px 发丝边、低饱和投影；卡片只做微交互，不做大位移。
  • 正文纸面单独保留白底和阅读行高，避免编辑界面抢走正文质感。

3主次操作

  • 发布、预览、设计说明固定在标题区右侧；复制到公众号放画布底栏，随时可见。
  • 选中块的常用动作（换图 / 拆分 / 合并 / 复制）放右栏，和「页面样式」分开，避免一屏出现两套同样按钮。
  • 发布前检查用轻量清单展示，待补项用琥珀色而非红色，减少压迫感。

4窄屏与触控

  • 容器变窄时自动切单栏：画布优先，样式库和页面样式变成底部抽屉，底部 dock 承载复制/样式入口。
  • 主要按钮高度 ≥ 36px，底部操作栏适配安全区；点「手机视图」可在同一页面预览 430px 宽度效果。

5待确认

  • 是否保留两级导航（平台 + 内容类型），还是把内容类型收进平台菜单？当前保留，因为切换频繁。
  • 是否把「设计说明」入口放进正式产品，还是仅原型可见？
  • 纸面宽度 / 字号是否再放大一档，按运营实际屏幕决定。

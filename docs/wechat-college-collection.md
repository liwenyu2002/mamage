# 学院动态目录：本地采集与逆向

## 边界

这是独立的本地 CLI，不启用生产定时任务，不连接数据库，不加载服务端环境文件，不启动 API、模型或工作队列。没有修改公共抓取器的 SSRF 策略。后端现有推文观察库和样式库不会因运行本工具自动增加记录。

只允许读取 `http://10.1.131.10/college` 及该页面实际公布的 `?page=N` 分页；另允许读取同站 `/robots.txt` 来检查采集规则。目录请求只使用 GET，不传认证信息、不跟随重定向，单次读取最多 8 MiB，15 秒超时。403、验证、跳转与解析异常不会被视为空目录。

文章仅通过原有 `wechat_article_source.fetchWechatArticleHtml` 获取，解析复用 `wechat_monitor_content.parseArticle`，后者调用既有整文逆向和样式抽取器。原文成功读取后保存正文块、文字、图片原始 URL、内联排版、样式块与视觉特征；不下载图片二进制，也不调用 AI 模型做文风总结。

## 使用

在仓库根目录运行：

```bash
node apps/server/scripts/collect_wechat_college.js --output .local/wechat-college-20261103
```

默认从 2024-01-01 起核验原文日期，每次请求间隔 2 秒，串行读取，遍历所有观察到的分页。没有文章总量额度。最小间隔 1 秒，单页大小限制仅用于资源安全。

- `--discover-only`：只抓目录，不请求原文。
- `--refresh-directory`：重新检查已观察分页，保留已有文章状态。
- `--reparse-directory`：仅重新解析本地目录 HTML；不会解除原文验证暂停。
- `--resume-blocked`：来源正常恢复后显式重试 blocked/failed；不自动重试身份隔离记录，也不绕过验证。
- `--since YYYY-MM-DD`：回溯开始日期；同一结果目录不允许更换日期，避免混淆数据范围。

连续两次源站访问限制会停止整个原文批次；429 立即停止，连续连接/读取错误最多三次后停止。暂停状态持久化，普通重启不会反复碰撞验证页面。不得通过换身份、复制登录 Cookie、自动解验证码等方式继续采集。

同一结果目录使用 `.collection.lock` 防止重复运行。异常进程退出后，先确认锁中 PID 已不存在，再移除该目录的锁；不要在另一个任务仍运行时删锁。

退出码：0 为执行完成（可能仅发现目录），2 为暂停或存在失败/隔离项，1 为配置或本地运行错误。退出 0 不代表已覆盖公众号全部历史。

## 本地文件

- `manifest.json`：分页、候选链接、每次尝试、失败原因和处理状态。
- `directory/*.html`：完整的原始目录页面证据。
- `articles/*.html`：成功获取的微信原文 HTML；解析失败时仍保留。
- `articles/*.json`：通过来源、日期核验后的逆向结果，结构兼容现有观察库文章解析结果。
- `report.json`：数量、日期范围、暂停原因、未落库标记。

`manifest.json` 只是目录和检查点，**不是逆向成果**。只有状态为 `reversed` 且存在 `articles/*.json` 才算成功提取。图片 URL 保留不等于图片已离线归档。后续导入观察库应显式走 `wechat_monitor_store.saveArticle` 的组织范围、事务和去重机制；本次没有增加自动落库开关。

## Fixes

1. Import `clearDirectMediaUrlCache` in the photo page. Both opening and saving
   the editor use the actual imported cache invalidation function.
2. Honor full-resolution source loading instead of silently reducing to 1280px.
3. Preserve server-provided baked edit metadata in the client display state.
   Render/save parameters still omit that metadata.
4. Do not cache full-resolution buffers transferred to the editor worker.
   Reopening now decodes usable original pixels rather than a detached buffer.

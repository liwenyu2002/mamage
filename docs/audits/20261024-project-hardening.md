# 项目收尾与生产验收

2026-10-24，学校站点通过 Kubernetes 发布。前端与 API 已更新，MySQL Pod 未重启；部署前后各组织媒体数量、文件夹状态与人物授权检查通过。首次验收基线为 `8132b5a6833e487f75ea7b1963c9f0107c8bf987`，后续补上数据卷容量探测，最终提交与镜像以服务器发布回执为准。此前已部署的散落源码已合入同一主分支，同步至 GitHub 和校内 Gitee。

## 已落实

- 前后端依赖审计均为零已知漏洞；学校虚拟 CPU 上实际验证 Sharp、无损像素、方向信息、色彩配置、HEIF 相关解码链、ResNet、FFmpeg 和浏览器运行时。
- 统一质量分档，消除中等照片同时落入不推荐结果的重叠；存储的严重缺陷标签优先于分数。
- 邀请码列表、分页与撤销均按创建者组织隔离；兑换校验组织，页面展示读取失败与重试状态。
- 三张旧模型缺失报错仅补齐质量评分并清除失败状态；逐字段核对原有描述、详细描述、人工标签、归属与媒体地址未变，未重置人物识别结果。
- 平台管理员账户页提供运行状态、后台队列、备份、检索耗时和评测信息；普通同学接口返回 403，未登录返回 401。告警记录到共享状态并在协调者上定期检查。
- 新闻稿增加段落与材料对照、段落改写任务、明确采用或放弃。任务具有持久化、配额、幂等和所有者隔离；刷新可恢复，正文改动后旧建议不可直接覆盖。真实模型任务与重复提交、跨用户访问测试通过，合成测试任务已清理。
- 正式发布入口改为学校 Kubernetes：固定提交、双端推送、私有配置备份、兼容镜像校验、完整后端测试、健康过渡 Pod、数据保护校验与回执。未执行迁移会阻止发布，不自动覆盖生产数据库。

## 备份恢复

每日 02:35（北京时间）通过独立 CronJob 导出数据库与运行配置，AES-256-GCM 加密后写入离机对象存储，并完整回读校验体积和 SHA256。加密密钥单独保管，不与运行 Secret 合并。首次实际执行成功，加密包约 225 MiB。

加密备份已下载到另一台设备，验证认证标签、SQL 与配置摘要，再恢复到新建的隔离数据库。全部 54 张表恢复成功，业务表数量和文件夹摘要一致；动态队列、检索日志和用量等运行表不以在线瞬时数量判定恢复成败。临时数据库与恢复明文已删除，保留加密备份和单独的密钥。

对象版本保护已开启。原件规则仅终止 7 天未完成的上传分片，不自动删除完整原件或其历史版本；加密备份保留 35 天并清理旧版本，保留其他存储规则。版本保护不等同于跨站点灾备。

## 验证范围

完整后端测试、前端审计和生产构建通过；Helm 渲染、危险配置拒绝、备份密钥隔离和部署预检测试通过；GitHub 使用受浏览器支持的 Ubuntu 24.04，持续集成通过。

浏览器测试覆盖 1440 与 390 像素：身份及人物权限、运行状态重试、段落改写刷新恢复、并发编辑保护、明确采用、文件夹共享、共享相册、范围检索与媒体查看。线上以平台管理员、普通同学完成只读验收；未修改已有账户密码或共享授权。

17 个固定算法回归用例通过，包含红背景、旁人红衣、颜色排除、弱绑定与未知动作等边界。这是确定性规则回归，不是实际检索准确率。新增人工标注导入与评测汇总，未导入完整标注前不报告真实准确率、召回率。

## 验收口径

- `npm run setup`；`bash scripts/ci.sh`；按 [.github/workflows/ci.yml](../../.github/workflows/ci.yml) 跑浏览器和 Helm 检查。
- `npm run test:workspace:isolated -- --docker` 新建临时 MySQL。真实回调和权限路由接收模拟 IAM 身份，测试既有账号绑定、组管理员改角色、普通成员被拒、共享搜索与详情、仅本人上传。
- 按 [Kubernetes 验收说明](../kubernetes.md) 从候选提交构建镜像，在独立本地集群测试。这里不使用真实 IAM 票据、生产数据库或对象存储凭据。
- 校园钉钉真扫码及学校网络入口需在正式预发验证，不能从模拟 IAM 推断其可用。

# 学院窗供图

学院窗只有一个可持续更新的供图池。MaMage 负责选图、确认和供图，不负责相框的选图、更新或展示。入口位于「学工与融媒体中心」工作空间的「学院窗」。

## 选图和发布

- 田心原、李文宇由部署时确认的 MaMage 用户 ID 授权。不按姓名自动授予权限，且不扩大两人已有的照片阅读权限。
- 使用自然语言选图，每轮显示匹配总数，可以继续加载后续候选。手动补图时，在相册把照片拖入中转站，再把中转站或其中一张拖到学院窗的候选区。也可点击「添加中转站照片」。暂时切走挑图不会丢掉已有候选。
- 「无人脸」和「无人」是硬筛选，按已有图像标签初筛，并排除冲突标签和已有人脸记录的图片。没有标签或尚未分析的图片不算通过；仍需看图确认，尤其是画面中的屏幕、墙上海报和小背景人物。
- 只提供指定小组拥有的照片，包括直接导入小组相册的 PhotoPlus 和喔图照片。不选视频、私有相册、其他小组的共享或转存图片，来源记录不明的照片也不会进入候选。照片或相册标记 `禁止外发` 等限制标签后，不可发布。
- 确认的是实际提供的 JPEG。保留保存的裁切和调色，不带原图地址或 EXIF。相册名、现有 AI 描述、有人手工确认且当前操作人可读取的姓名随图提供，不另设审核步骤。含明显敏感内容的字段整体省略；裁切、旋转或标记 `已脱敏` 的图不带原图的姓名和描述。仍应人工检查画面中的证件、个人信息和其他不宜对外展示的内容。
- 可以逐张预览，也可以在「批量发布」一次确认当前候选或本轮全部匹配。后者包含未加载页面，以本轮检索时的结果为准，不纳入后续新增的照片；两种范围都会保留手动排除项。任务在后台逐张复核供图范围和可用性，页面刷新后可继续查看进度。停止任务不撤回已经发布的照片。批量处理不等同于人工检查内容。
- 发布后保存当时的画面和文字。源图删除、移出范围或被限制会自动撤回；解除限制不会让旧发布重新出现。也可在「已发布」手动撤回。撤回只影响今后的查询和下载，已经下载的副本无法收回。

## 内网对接

普通 MaMage 域名不提供此接口。对接服务从受控内网访问 MaMage API 的私有地址，使用服务端 Key。不要从浏览器、电子相框或客户端分发 Key，也不要复用 MaMage 用户登录令牌。

| 请求 | 说明 |
| --- | --- |
| `GET /api/integrations/college-window/v1/photos?limit=50` | 当前已发布记录。每页最多 200 张。返回 `{ photos, nextCursor }`，有下一页时原样回传 `after=nextCursor`。 |
| `GET /api/integrations/college-window/v1/photos/{id}/image` | 取单张 JPEG，长边不超过 1920，不放大原图，每张不超过 2 MB。不存在、未发布或被撤回时返回 404。 |

每个请求都要求 `Authorization: Bearer <服务端 Key>`。列表每项有 `id`、`width`、`height`、`sha256`、`publishedAt`、`albumName`、`peopleNames`、`description`、`imagePath`；未提供的文本为 `null`，无人名时为 `[]`。`imagePath` 相对于同一内网 API。没有 ZIP、原图或视频接口。对接方可以多页读取并逐张下载，把 JPEG 和对应文字预存到自己的服务，断网时使用。成功拉完整份列表后，以该列表为准对齐本地缓存；同步期间的变动将在本次或下次完整同步中看到，网络故障时保留上一次完整结果。

## 部署配置

默认不开启。在 API 服务的运行配置中设置：

| 变量 | 值 |
| --- | --- |
| `MAMAGE_COLLEGE_WINDOW_ORG_ID` | 学院 ID |
| `MAMAGE_COLLEGE_WINDOW_UNIT_ID` | 学工与融媒体中心的小组 ID |
| `MAMAGE_COLLEGE_WINDOW_MANAGER_IDS` | 经核对的田心原和李文宇的 MaMage 用户 ID，逗号分隔 |
| `MAMAGE_COLLEGE_WINDOW_CONSUMER_TOKEN_SHA256` | 专用随机 Key 的 SHA-256 十六进制摘要（原始 Key 仅在对接服务的密钥管理中） |
| `MAMAGE_COLLEGE_WINDOW_CONSUMER_PEERS` | 允许的直连源 IP 或受控子网，逗号分隔。不会信任 `X-Forwarded-For`。 |

先应用学院窗的数据库迁移（包括 `20261126_001_college_window.sql` 和 `20261126_002_college_window_direct_imports.sql`，迁移账号需要建触发器权限），再开启配置。仅向受授权的对接服务开放私有路径，并验证互联网上的 Web 或反代不能到达该路径。展示图存放在对象存储的 `integrations/college-window/`，该前缀必须保持私有，不能通过匿名 COS、CDN 或通用资源代理读到。

本地开发的 `.local/dev/college-window.json` 使用同名配置的对应字段：`dbName`、`orgId`、`unitId`、`managerIds`、`consumerTokenSha256`。只接受当前本地数据库名、权限为 600 的文件；本地取图只允许回环地址。本地配置和密钥文件不进 Git。

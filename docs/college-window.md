# 学院窗供图

学院窗只有一个可持续更新的供图池。MaMage 负责选图、确认和供图，不负责相框的选图、更新或展示。入口位于「学工与融媒体中心」工作空间的「学院窗」。

## 选图和发布

- 田心原、李文宇由部署时确认的 MaMage 用户 ID 授权。不按姓名自动授予权限，且不扩大两人已有的照片阅读权限。
- 使用自然语言选图，每轮显示匹配总数，可以继续加载后续候选。手动补图时，在相册把照片拖入中转站，再把中转站或其中一张拖到学院窗的候选区。也可点击「添加中转站照片」。暂时切走挑图不会丢掉已有候选。
- 「无人脸」和「无人」是硬筛选，按已有图像标签初筛，并排除冲突标签和已有人脸记录的图片。没有标签或尚未分析的图片不算通过；仍需看图确认，尤其是画面中的屏幕、墙上海报和小背景人物。
- 只提供指定小组拥有的照片，包括直接导入小组相册的 PhotoPlus 和喔图照片。不选视频、私有相册、其他小组的共享或转存图片，来源记录不明的照片也不会进入候选。照片或相册标记 `禁止外发` 等限制标签后，不可发布。
- 新发布只登记原图链接，不读取、裁切、转码或复制文件。已有的供图 JPEG 保持不变，不会切换成原图。原文件可能含拍摄信息或未裁切的内容，持链接的人无需登录即可查看和下载。标记过脱敏或不公开姓名的原图不可发布。相册名、现有 AI 描述、人手工确认且当前操作人可读取的姓名依然只随内网清单提供，含明显敏感内容的字段整体省略。
- 可以逐张预览，也可以在「批量发布」一次确认当前候选或本轮全部匹配。后者包含未加载页面，以本轮检索时的结果为准，不纳入后续新增的照片；两种范围都会保留手动排除项。任务在后台逐张复核供图范围和可用性，页面刷新后可继续查看进度。停止任务不撤回已经发布的照片。批量处理不等同于人工检查内容。
- 发布时记住原图地址、确认姓名和当时的描述；相册路径和内容标签随图库更新。源图替换、删除、移出范围或被限制会自动撤回；还原或解除限制不会让旧发布重新出现。也可在「已发布」手动撤回。每次打开分享链接会取得有效期 1 分钟的临时对象存储地址；撤回后分享链接立即失效，已下载的副本无法收回。

## 内网对接

学校内网入口是 `http://10.1.131.37`。只有该 IP 的站点接收学院窗接口请求；其他站点入口仍不提供清单。对接服务在后端使用专用 Key 调用，不把 Key 放在相框或前端代码里。人工查看时可打开 `/college-window-feed`，填入同一个 Key；页面退出或刷新后需要重新输入。原图的单张分享链接仍可直接打开，接收方的网络需能访问对应对象存储。

| 请求 | 说明 |
| --- | --- |
| `GET /api/integrations/college-window/v1/photos?limit=50` | 当前已发布记录。每页最多 200 张。返回 `{ photos, nextCursor }`，有下一页时原样回传 `after=nextCursor`。 |
| `GET /api/integrations/college-window/v1/photos/{id}/image` | 新发布的原图返回 302，请跟随跳转；历史供图直接返回 JPEG。不存在、未发布或被撤回时返回 404。 |

内网请求均要求 `Authorization: Bearer <服务端 Key>`。列表每项有 `id`、`width`、`height`、`sha256`、`publishedAt`、`albumName`、`peopleNames`、`description`、`tags`、`imagePath`；未提供的文本为 `null`，无人名或标签时对应数组为 `[]`。原图不额外读取宽高或计算校验和，这三项为 `null`，并额外返回可从普通 MaMage 入口打开的 `publicImagePath`，附 `?download=1` 可下载原文件。没有 ZIP 或视频接口。对接方可以多页读取并逐张下载，把原文件和对应文字预存到自己的服务，断网时使用。成功拉完整份列表后，以该列表为准对齐本地缓存；网络故障时保留上一次完整结果。

`albumName` 是来源小组中的完整相册路径，例如 `校园影像 / 迎新 / 报到 / 现场照片`。顶层相册只返回相册名；未归入相册时为 `null`。有多个有效位置时优先最深的路径，同深度遵循小组桌面的文件夹顺序；不公开私人目录、快捷方式、智能相册或带有限制外发字样的路径。移动或重命名后，已发布照片重新读取清单时自动显示最新路径。

`tags` 是照片在图库中的现有内容标签（如 `["室外","校园建筑","全景"]`），对已发布记录实时读取，无需重新发布。仅返回允许外发的常见场景、活动和构图等词汇，不包含自由填写的内部备注、审核标签、姓名或联系方式。网页在卡片上展示部分标签，在预览中展示全部。AI 内容标签只供选图参考，不代表人工脱敏确认。

跟随原图重定向时不要把 `Authorization` 转发给对象存储地址。每次下载从返回的 `imagePath` 或 `publicImagePath` 开始，不缓存对象存储临时地址。

## 部署配置

默认不开启。在 API 服务的运行配置中设置：

| 变量 | 值 |
| --- | --- |
| `MAMAGE_COLLEGE_WINDOW_ORG_ID` | 学院 ID |
| `MAMAGE_COLLEGE_WINDOW_UNIT_ID` | 学工与融媒体中心的小组 ID |
| `MAMAGE_COLLEGE_WINDOW_MANAGER_IDS` | 经核对的田心原和李文宇的 MaMage 用户 ID，逗号分隔 |
| `MAMAGE_COLLEGE_WINDOW_CONSUMER_TOKEN_SHA256` | 专用随机 Key 的 SHA-256 十六进制摘要（原始 Key 仅在对接服务的密钥管理中） |
| `MAMAGE_COLLEGE_WINDOW_CONSUMER_PEERS` | 允许的直连源 IP 或受控子网，逗号分隔。不会信任 `X-Forwarded-For`。 |

学校入口由主机 Nginx 区分，集群网站不开放清单路径。学校模式中 API 的直连对端是主机网关，主机入口检查校内源地址。先配置 Key 摘要和主机的直连地址并完成应用发布，再在校内服务器运行 `node scripts/configure-college-window-edge.cjs --apply`，仅更新学院窗的两条路由，切换前会保存旧配置并验证 Nginx。

先应用学院窗的数据库迁移（包括 `20261126_003_college_window_original_links.sql`，迁移账号需要建触发器权限），再开启配置。升级前待旧版本正在处理的批量任务完成；旧确认不会自动变成原图发布。仅向受授权的对接服务开放清单路径。历史展示图的 `integrations/college-window/` 和原图存储继续保持私有，不开启对象桶的匿名权限。

本地开发的 `.local/dev/college-window.json` 使用同名配置的对应字段：`dbName`、`orgId`、`unitId`、`managerIds`、`consumerTokenSha256`。只接受当前本地数据库名、权限为 600 的文件；本地取图只允许回环地址。本地配置和密钥文件不进 Git。

# 校园模型接口接入与隔离测试

日期：2026-10-15。最初完成隔离测试，随后用户明确要求不灰度、直接全量切换。现已部署 Helm revision 10：人脸、拍照找我、照片语义/评分、衣着核验和视频抽帧均使用校内 Hub。未重跑人物库、未修改数据库结构；本轮未推送代码。

## 接口选择

- 人脸使用 `POST /v1/face/embed`，一次取得检测框、关键点和向量，不重复调用检测接口。请求为 JPEG/PNG 二进制，响应像素坐标转换为 MaMage 的比例坐标。[官方说明](https://hub.zgci.org/docs/models/face-embed.md)
- 图片批量分析及逐人物衣着核验优先 `qwen`，当前别名对应 Qwen3.6-35B-A3B；关闭思考，直接发送图片字节的 data URL，不向平台暴露私有 S3 凭证、内部图片地址或短期签名链接。[官方说明](https://hub.zgci.org/docs/models/qwen.md)
- `smart-router-v2` 可配置，但它由 GLM 作答、Qwen 看图，适合多轮综合问答，不作为本轮批量看图默认通道。[官方说明](https://hub.zgci.org/docs/models/smart-router-v2.md)

官方入口为 `https://llm.inner.bza.edu.cn/hub`。密钥在被 Git 忽略的私有配置中，本文和源码不含密钥。

## 隔离实测

固定照片来自此前获准的本地测试样本，标签沿用先前目视检查，不是独立人工标准答案；均为串行小样本，不代表并发吞吐或全库准确率。

| 项目 | 结果 |
| --- | --- |
| 新旧人脸输出 | 3 张照片、7 张脸均可按位置一一对应 |
| 同脸向量余弦相似度 | 0.9999356–0.9999861 |
| 检测框 IoU | 约 0.9997–0.9999 |
| 人脸接口端到端 | 这批样本约 0.05–0.72 秒，包含网络与解码；检测/特征接口分别计时 |
| Qwen 人物衣着 | 六张不同照片的调用约 0.67–0.78 秒；红衣、黑衣加红背景、蓝衣加洋红背景、浅色衣加红色道具的检查与目视标签一致 |
| 智能路由 | 相同红衣样本约 8.63 秒；此前另一轮 12.51 秒 |
| 学校 API 容器独立进程 | face/embed 约 0.137 秒；完整照片简短描述约 0.444 秒，TLS 验证保留 |

整图语义/技术质量/选片评分的独立样本约 1.5 秒，不应把较短的衣着核验耗时冒充整套分析耗时。模型评分仍沿用现有映射，本次没有校准选片准确率。

Qwen 首版提示曾使模型复述 JSON Schema，而非输出观察数据。已明确区分 Schema 与数据实例，并增加类型、必填字段、枚举、额外字段和截断检查；修复后固定样本通过。任意思考文字不作为正文或视觉证据。

真实整图回放还暴露旧后处理问题：模型的 `多人` 标签会因描述出现“一名男子”而被改为 `单人`，即使同一句描述还有其他人。已去掉这种描述推断；明确的视觉标签保留，冲突的单人/多人标签均不采纳。新增回归先复现失败、再验证修复，不通过增加姓名或背景关键词特判。

## 已实现的边界

- 统一 HTTPS、服务端 Bearer 鉴权、禁止重定向携带密钥、有界超时、有界响应读取、脱敏错误。
- 相册人脸检测与拍照找我复用同一适配器。检测结果先严格验证，再进入原有身份匹配；不接管组织/小组/相册/分享权限。
- 默认人脸结果标记为隔离空间 `hub-buffalo_l-unverified`。相册写入和自拍查询的 Hub 分支在兼容性未批准时拒绝运行，不能意外创建一批新身份。
- 仅经进一步确认与旧 `buffalo_l/null` 空间兼容后，才可设置 `FACE_HUB_LEGACY_SPACE_APPROVED=1`。小样本高相似度是良好证据，但不能代替权重/预处理确认、困难样本与错误匹配率校准。
- 图片语义和选片保留原有技术实测与评分映射，不因切到远程接口而静默丢失质量评分。WebP 会在服务端转换为 JPEG；前端不接触密钥。
- 衣着证据缓存按 provider、地址、模型修订分离；远程别名会升级，发布时须记录模型修订并维护失效策略，不能把稳定别名当作永不变化的权重。
- 视频抽帧已增加并启用同一 Hub 适配分支；时间轴、视频优先级和总语义机制保持。声音转写和新闻文本模型未迁移。

## 上线与后续

1. 用户已批准直接复用旧 buffalo_l/null 空间。已实测真实自拍匹配旧库；部署前后 17,621 张人脸的位置/身份关联、人物、相册和文件夹摘要一致。仍应扩充困难样本并核验服务方权重版本，小样本数值一致不等于完整准确率认证。
2. 确认平台的人脸向量与调用结果日志留存政策。与原有仅本地推理不同，官方明确说明平台会记录调用结果和人脸特征；智能路由还会缓存看图结果。[人脸文档](https://hub.zgci.org/docs/models/face-embed.md)、[路由文档](https://hub.zgci.org/docs/models/smart-router-v2.md)
3. 灰度名单已移除，组织、小组和人脸授权不变。旧配置、Secret 和镜像保留，可回退 revision 9；不得恢复旧数据库覆盖业务数据。模型修订改变只使派生衣着证据失效，没有删除旧人物或原图。
4. Linux 最终镜像的后端测试和新增 13 项适配测试通过。生产真实入口实测：人脸约 0.53 秒、限定相册范围的自拍匹配约 0.10 秒、整图语义/评分约 2.28 秒；单帧视频接口契约约 0.56 秒，不代表长视频总耗时。电脑/手机公网检查另有私有记录。

# MaMage

**面向校园融媒体工作的素材管理与内容创作平台。**

MaMage 将照片、视频、人物档案与编辑工具连接起来，服务校园新闻宣传、党团活动记录和日常媒体协作，让素材从收集、整理到检索、创作和分享形成完整工作流。

## 核心功能

- **素材归档**：统一管理活动照片与视频，通过多级文件夹、相册和活动环节整理素材，支持上传与外部相册链接转存。
- **智能检索**：结合语义标签、人物与视频时序信息寻找素材，支持相似照片浏览和“拍照找我”。
- **人物档案**：维护学院共用人物库，支持人脸合并、拆分与人工纠错，人脸检索按权限开放。
- **全媒体编辑台**：提供推文排版、模板收藏、AI 新闻稿生成和视频编辑工具，衔接素材管理与内容生产。
- **团队协作**：按小组织划分工作空间，支持相册共享、协同编辑、独立复制和公开链接分享。

## 产品体验

采用液态玻璃界面，适配电脑与手机，提供玻璃堆叠与经典多栏两种文件夹视图。照片支持非破坏性调色预览与调色后下载；耗时的转存、分析与视频处理在后台完成，页面持续展示任务状态。
